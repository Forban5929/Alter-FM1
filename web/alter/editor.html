ALTERLes réglages des trois sons de ta FM-1, en grand

Pas connecté
Patch sur l'ordinateur
Scène dans la FM-1

Branche ta FM-1 en USB, allume-la sur ALTER, puis clique sur « Connecter la FM-1 ». Chrome ou Edge demandent l'autorisation d'échanger des messages MIDI avec la machine : accepte.

  1. Ce que tu bouges ici change le son tout de suite sur la machine, et ce que tu tournes sur la machine bouge ici.
  2. « Enregistrer » garde les trois sons dans un fichier sur ton ordinateur, à partager avec qui tu veux.
  3. « Ranger ici » garde toute la scène en cours (sons, rythmes, effets) dans une place USER de la machine, comme SAVE tenu.

Pas de machine sous la main ? « Essayer sans machine » fait tourner ALTER dans la page, sans le son.

ALTER est un firmware libre (GPL-3.0) construit sur Felucca. Code : github.com/Forban5929/Alter-FM1.
